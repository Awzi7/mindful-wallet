# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project targets SDK 54 specifically because the Expo Go app on the Apple App Store is
pinned to SDK 54 (newer SDKs are stuck in Apple review — see Expo's changelog). Do not bump
the `expo` package past 54.x without re-checking Expo Go's currently supported SDK version,
or real-device testing via Expo Go will break with "Project is incompatible with this version
of Expo Go".
